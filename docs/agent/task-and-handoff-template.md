# Task and handoff template

Copy the relevant section into a Herdr assignment or other agent task. Keep scope narrow enough that ownership and completion can be verified.

## Assignment

```markdown
# Task: <outcome-oriented title>

## Objective

<The concrete result this task must produce.>

## Governing context

- PROJECT_BRIEF.md
- <relevant context documents and decision records>

## Scope and owned files

- <files or areas this agent may change>

## Inputs and dependencies

- <available evidence, assets, preceding tasks, or blockers>

## Acceptance criteria

- [ ] <observable result>
- [ ] <required validation>

## Non-goals

- <related work excluded from this task>

## Decisions requiring escalation

- <choices the agent must present rather than make>
```

## Handoff

```markdown
# Handoff: <task title>

## Outcome

<What is now true.>

## Files changed

- <path and purpose>

## Assumptions and decisions

- <assumption, supporting evidence, and consequence>

## Validation

- <command or review performed and result>

## Open questions and risks

- <remaining uncertainty and recommended owner>

## Suggested next task

- <smallest useful follow-up, if any>
```

Do not include hidden reasoning, credentials, personal customer data, or raw conversation logs in a handoff.
